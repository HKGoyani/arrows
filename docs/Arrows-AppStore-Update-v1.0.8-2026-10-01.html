Paste into App Review Information → Notes. 1963 chars. Different audience from What's New: what changed under the hood and how to verify it.

Arrows - Escape Puzzle is a single-player offline puzzle game. No login or account is required to play. This build (1.0.7 -> 1.0.8) changes ad-delivery behaviour only. No gameplay rules, purchases, permissions, or data collection changed: - The app-open ad (shown when the user returns to the app) now appears only after the app was actually sent to the background. Previously, briefly opening Control Center or Notification Center could also trigger it. - Ad requests were reduced: the post-win and lives-refill ads are requested once per level attempt, retries stop when a level attempt ends, and the Restart ad is requested only when the Restart confirmation is actually shown. - The Home banner, if it finishes loading just as the user starts a level, is now kept and shown on return to Home instead of being discarded. - Firebase Analytics (anonymous, aggregated, no PII): the banner ad_shown event now logs on a real impression rather than on load, and one new event, ad_discarded (ad unit name + reason), was added to the existing usage events. - Built with an updated Flutter SDK (3.47.5). To observe the app-open change: leave the app with the Home gesture, wait a moment, and return - an ad may show (at most once every 3 minutes). Pulling down Control Center and dismissing it does not trigger one. Unchanged from the previous submission: - All gameplay progress is stored locally on-device (no server backend). - One in-app purchase: "Remove Ads" ($3.99, non-consumable, product ID remove_ads) disables banner/interstitial/app-open ads. Rewarded ads (opt-in, for hints/extra lives) remain available even after purchase by design - disclosed in the purchase description shown in Settings. - Ad mediation is Google AdMob with Unity Ads only. - No account creation, no chat, no user-generated content, no web view with unrestricted browsing. Test path: tap Play on the Home screen to start the current level, or Level 1 (tutorial) on a fresh install.
