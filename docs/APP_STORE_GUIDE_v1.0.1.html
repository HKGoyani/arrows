12. App Review Notes

Paste this into the "Notes" field on submission (updated from v1.0.0 to mention what changed):

Arrows – Escape Puzzle is a single-player offline puzzle game. No login
or account is required to play.

This is a minor update (1.0.0 → 1.0.1) that:
- Adds AdMob mediation (Meta Audience Network, Unity Ads) as additional
  ad sources alongside Google AdMob — same ad formats and placements as
  before, no new ad behavior visible to reviewers.
- Fixes a display bug on the Daily Challenge calendar screen (future
  days in the month were not rendering).

Unchanged from the previous approved version:
- All gameplay progress is stored locally on-device (no server backend).
- One in-app purchase: "Remove Ads" ($3.99, non-consumable, product ID
  remove_ads) disables banner/interstitial/app-open ads. Rewarded ads
  (opt-in, for hints/extra lives) remain available even after purchase
  by design — disclosed in the purchase description shown in Settings.
- Firebase Analytics is used for anonymous, aggregated usage events only
  (no PII collected).
- No account creation, no chat, no user-generated content, no web view
  with unrestricted browsing.

Test path: tap Play on the Home screen to start Level 1 (tutorial),
or tap an in-progress level number to continue. To see the calendar
fix, open the Challenge tab.
